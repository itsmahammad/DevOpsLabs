# DevOps Labs

Hands-on DevOps labs and infrastructure exercises completed during the **Ironhack DevOps Engineering Program**.

## Overview

This repository contains lab exercises, configurations, and deployment experiments built throughout the Ironhack DevOps program.

The goal is to strengthen real-world DevOps skills by working with modern infrastructure tools and deployment workflows rather than only learning theory.

Topics include:

- Linux administration
- Networking fundamentals
- Git & GitHub workflows
- Docker & Docker Compose
- CI/CD pipelines
- Cloud infrastructure
- Infrastructure as Code
- Configuration management
- Monitoring & automation
